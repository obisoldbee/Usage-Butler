## 采纳的 Mac 范围

原生 SwiftUI/macOS 13；保留额度、内存、设置。下载包是设计参考，网页原型及其测试不是原生运行证明。Windows 的内存 commit 指标和合仓建议未迁入 Mac。设置仍即时保存，飞书检查改为用户显式发起且旧配置结果失效。

|整改项|当前实现|验证边界|
|---|---|---|

## 运行演示

```bash
./script/build_and_run.sh --fixture-panel
```

只在 Debug 加载离线 fixture；独立验证窗口复用 `PanelRootView`。静态 fixture 会真实进入过期状态，点“刷新”重新载入样例，不能用它证明真实采集。可追加 `--network-v2-dark` 到 Debug 预览启动参数检查深色。正式版为菜单栏应用。

## 能力与后续门

Production 只有接口观察，不相加物理/TUN/回环，不猜Wi-Fi或代理软件归属。真实应用/连接归属、系统扩展授权、阻断、磁盘历史和网络提醒仍未实现，不是完整P0或防上传产品。Debug规则不会操作系统；导出是演示数据，不是网络取证结果。没有 HTTPS 解密、载荷采集、流量上传或自动发送消息的新能力。

数据细节见[原生技术合同](network-v2-contract.md)，评审入口见[review guide](network-v2-review-guide.md)。完整端到端验证收据保存在本地项目审查记录，公开记录只描述本次实际执行范围。
