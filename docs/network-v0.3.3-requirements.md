# 0.3.3（6）macOS 采纳需求与边界

本文件供独立源码审查使用。范围为原生 SwiftUI/macOS 13+ 网络模块审查修复，并保留既有额度、内存和设置行为。比较基线为公开提交 `4c72942df298d4cdf321c7b98cb635c8707d01a9`。需求采纳与实际验证分别记录；历史测试、提取模型、截图和构建不能替代本次生产类型或原生运行证据。

|需求|采纳行为|应检查的证据|
|---|---|---|
|F01 停止与最新意图|先停运行，保存串行；旧 load/save/clock 不能重启 source 或发布；保留启动前意图、重复启停及 stop→start；最终 shutdown 拒绝晚到工作并 drain 已接受保存|真实 NetworkCollector 的暂停 load/save/clock 测试、最终保存值、失败与退出交错|
|F02 当前接口状态|完整成功枚举才证明 present/missing；失败/断连 unknown，停止 notObserved；成功空集合与失败分开；手选不暗换，历史有界|reader→source→aggregator→snapshot→resolver→UI；旧 codec 无证据为 unknown；恢复/index变化重基线、不桥接、不跨段结算|
|F03 路径时效|5秒复用、15秒确认使用可注入单调时间；wall变化不延长有效期；sleep/wake失效、唤醒重读；设置无流量时持续更新时效|边界、前跳/后退、失败、断连、停止和独立设置模型测试|
|F04 来源常驻|通用与网络设置均常驻“演示数据 · 非本机采集”视觉/AX标识；生产显示真实来源；Release排除fixture|两页原生读回、Release构建与字符串/源码排除检查|
|F05 零/未知|observedPeak可空；无样本、基线、单向nil、范围外数据为未知；已知全零为0；轴fallback不充当观测|视觉/AX共同模型与原生未知读回、全零和单向测试|
|R01 身份与重算|源点ID独立于窗口/数组下标；各向连续段裁切后稳定；缓存历史投影、隔离游标；保留缺口/峰谷/独立轴/时间推进|ID/历史裁剪/缓存失效测试；7200点、密集/多缺口、hover及范围切换的阶段分位数|
|设置回归|网络直达不触发通用飞书检查；保留 larkCheckRevision、即时保存、刷新/登录/重检/CLI路径、产品显隐与缓存诊断|页级检查路由测试与原生设置往返，禁止自动发送测试消息|

原生交互必须走查五档文字外坐标、间隙、网络设置直达/返回、来源、图表固定→Escape→Tab，以及 Picker/TextField 焦点。图表每个时间按钮仍有至少32pt高度、完整矩形命中，菜单面板宽540pt且按内容自适应；不恢复主面板折叠。

性能测量必须绑定工作负载、样本数、平台、版本和计时边界，给p50/p95/p99/max。同步 Swift 测试阶段不是系统 layout/draw/present，也不是输入到屏幕延迟；没有 trace 的阶段明确 Unknown，不承诺完全消除卡顿。旧 macOS、完整 VoiceOver、x86_64 真机、全部缩放/桌面组合及两小时真实浸泡分别验收。

真实来源仍只有接口字节计数（公开 IFMIB）。不合计物理/隧道/回环，不猜代理软件归属；没有按应用/目标采集、连接阻断、系统扩展、磁盘历史或网络提醒。Debug规则只在演示会话内；不触发模型调用、登录、凭据读取、流量上传或外部消息。不修改系统时间或用户网络来验证时效。
