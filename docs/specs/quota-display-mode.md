# 额度展示方式

本合同定义额度百分比行的全局本地展示选择。继承现有 Provider、缓存、历史、安全及告警合同，仅改变呈现。设置位于通用设置，名称为“额度展示方式”，选项依次为“跟随来源”“统一已用”“统一剩余”。默认跟随来源，现有用户无需启用步骤。切换立即作用于所有产品、窗口和周期的百分比行，本机持久保存，重开仍生效。未知或损坏的保存值回退跟随来源。

## 原始需求与确认

需求是保持官方形式，或统一展示当前阶段已用，或统一展示当前阶段剩余。用户确认，OpenAI 来源剩余21%时，统一已用应显示“已用79%”，原例中的“剩余79%”为笔误。该行条长79%，颜色仍为红色。

用户还确认了条方向，已用从左端向右增长；剩余从满条开始，消耗时右边界向左缩短，保留段始终贴左端。0%空轨，100%满轨，三种模式使用同一宽度的轨道。

## 数值与详情

跟随来源保留现有方向、官方整数文案和原始读数。OpenAI 显示剩余，MiniMax 和 Grok 等保持现有来源方向。

统一模式使用原始有限且有效的精确百分比。同方向保留精确比例，反方向用100减原始比例；不能用已取整文案作补数。换算后的精确比例决定条长，文案统一向下取整，正值不足1%显示1%，0保持0。同方向也使用这套统一文案。VoiceOver 与当前主行、进度条采用同一方向和数值文本。详情以“来源读数”区分来源方向及精确值，保留既有来源详情。

Grok 共享周额度跟随来源时保留官方规则，0显示0，正值不足1显示1，其余向下取整。精确已用67%转为剩余33%；精确已用67.89%转为剩余32%，条长32.11%。月额外用量及积分继续独立显示。

异常、未知、缺失、非有限、零预算及超额保持明确状态；不通过截断强制变成有效百分比。无限额度、次数、视频赠送、重置权益、余额、积分和月额外用量沿用各自语义。

## 颜色及副作用

颜色始终由有效来源的可用份额决定，可用[0,30]红、(30,60]黄、(60,100]绿。超过生效刷新间隔加10分钟的来源显示失联灰；仅手动刷新时不按年龄判失联。原采集时间保留，切换展示方式不改变同一额度的颜色。

切换只写本地展示偏好，不触发 Provider、网络、登录、缓存清理或额度告警，不修改 Domain、缓存、数据库和计量含义。多个产品或周期分别换算，不合并额度。常规设置只说明本地显示与颜色按可用额度。

## 验证范围

针对性测试应覆盖默认、持久化、非法值、所有来源方向、多产品、多窗口、0/100、小数取整、30/60颜色边界、Grok官方文案转换、stale及失联、非百分比、切换无Provider或告警副作用。原生视图验证应对同一组人工样本分别检查三种模式的文字、实际填充长度、左右端及颜色，并提供设置默认与保存后的结果。原生离线样本渲染、正式运行和真实账户验证分别报告。开发候选通过相关测试和双架构Release构建，完整测试集或平台矩阵未执行时明确列出。
